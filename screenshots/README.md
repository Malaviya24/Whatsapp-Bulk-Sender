# Screenshots

This folder is for screenshots used in the main README.

## Recommended Screenshots to Add

1. **dashboard.png** — Main dashboard with stats
2. **connect.png** — QR code page
3. **send.png** — Send messages page with form filled
4. **history.png** — Message history with filters
5. **tray.png** — System tray icon menu
6. **settings.png** — Settings page

## How to Capture

1. Use Windows Snipping Tool (Win + Shift + S)
2. Save as PNG (better quality than JPG for UI screenshots)
3. Name files in lowercase with hyphens: `dashboard.png`
4. Reference them in main README:
   ```markdown
   ![Dashboard](screenshots/dashboard.png)
   ```

## Tips

- Use a clean test session (no personal data visible)
- Make the window 1280x800 or similar standard size
- Use realistic but fake data (e.g., +1234567890)
- Show different states (empty, mid-sending, completed)
